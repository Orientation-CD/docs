# Report template editor retired

The former `/admin/report-templates` raw HTML/Jinja editor and enterprise/default report-section configuration have been removed from the current backend. This retained documentation URL exists for older bookmarks.

Use [Design reports and editable PowerPoint](/backend/reports) for current 9/13/17-page Blueprint products, [Prompts](/admin/prompts) for editable generation instructions, and [Workflows](/admin/workflows) for node model selection. Prices and subscription access live in [Billing](/admin/billing).

Historical compatible report outputs remain governed by their stored publication contracts. Do not recreate the removed editor, tables or quote/report-item workflow from an old guide.
